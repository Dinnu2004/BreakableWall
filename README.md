# Dash Through Breakable Objects

Unity 6 learning prototype: high-speed dash movement with full-path SphereCast/Raycast detection, breakable targets, cooldowns, VFX, SFX, and a small primitive-based arena.

Controls: WASD/arrows to move, Space to dash, Q to compare SphereCast and Raycast, R to reset.

Open the project in Unity 6 from the `DashBreakLab` folder.
